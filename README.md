# Ebbo

Responsive landing page for the Ebbo subscription app. Open index.html to preview. No build required.

## GitHub Pages

In Settings → Pages, choose Deploy from a branch, then main and / (root), and Save. GitHub will display the site URL after deployment. Pages availability for a private repository depends on your GitHub plan. If unavailable, make this repository public only if you want its source code visible.

The app preview contains illustrative sample data. Add real app store links when available.
